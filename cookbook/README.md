# Sopo 쿡북 — 로봇팔 학습 경로

HopeJr 부품으로 제작한 커스텀 중형 로봇 암(Feetech STS/SMS 시리얼 버스 서보)을 처음 켜는 사람이
순서대로 따라가며 이해할 수 있도록 주제별 폴더로 나눴다. 폴더 번호가 곧 진행 순서다:
연결 확인 없이 자세를 논할 수 없고, 범위 실측 없이 안전 캡을 정할 수 없고,
안전 캡 없이 토크 모델 튜닝으로 넘어가면 안 된다.

| 폴더 | 주제 | 언제 |
|---|---|---|
| [1_setup](1_setup/) | 연결 확인 · ID 설정 · 첫 구동 · 토크 OFF | 조립 직후 가장 먼저 |
| [2_pose_calibration](2_pose_calibration/) | 관절 범위 · 연속 관절 · 자세 기록 · URDF zero/방향 | 팔이 움직이기 시작한 뒤 |
| [3_safety_torque](3_safety_torque/) | 자중 토크 실측 · 토크 캡 · EPROM 영구화 · 리플렉스 판정 | 사람 근처에서 돌리기 전 |
| [4_torque_model](4_torque_model/) | 토크 캡 검증 · 중력 모델 대조 · PID/흔들림 튜닝 | 안전 캡이 잡힌 뒤 |
| [5_gripper](5_gripper/) | (플레이스홀더) 그리퍼 장착 작업 브리프 | 그리퍼 도착 시 |

각 폴더의 README에 스크립트별 사용법과 완료 기준이 있다.
모든 스크립트는 **repo 루트에서** 실행한다 (`configs/` 기본 인자가 CWD 기준).
sopod(데몬)가 떠 있는 동안은 쿡북 스크립트가 버스를 잡을 수 없다 (포트 락).
